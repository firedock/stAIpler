The Problem

Scattered context, generic output

Every AI tool has its own instruction file. None of them talk to each other. Your agent gets fragments instead of a complete picture.

😶

No identity

Without an identity layer, your agent doesn't know what role it plays. It gives generic responses instead of acting as your domain expert.

⚠️

No guardrails

Without constraints and policies, the agent has no safety boundaries. It may introduce dependencies, leak PII, or ignore your coding standards.

🔬

No measurement

You have no way to know if your instruction files are working. Are they complete? Are they effective? Is the agent actually following them?

🧩

Fragmented ecosystem

CLAUDE.md, AGENTS.md, .cursorrules, copilot-instructions.md, SKILL.md — every tool expects a different file. You maintain duplicates or have gaps.

How It Works

Like jest --watch for your AI context

stAIpler gives you constant, live visibility into your agent's context quality.

1

Scan

Discovers instruction files across 30+ formats. CLAUDE.md, AGENTS.md, .cursorrules, SKILL.md, copilot-instructions — all detected automatically.

2

Analyze

Maps files to 12 instruction layers and scores coverage with an Empowerment Score. Identifies what's missing and what's weak.

3

Watch

Live terminal dashboard updates as you edit instruction files. See your score change in real-time, like jest --watch for AI context.

4

Optimize

AI generates missing layers using your existing project context. Press 'o' in watch mode to optimize on the fly.

5

Inject

Writes your agent's blind spots directly into its config file. The agent literally knows what context it's missing. No other tool does this.

6

Gate

CI command enforces minimum scores and required layers in your pipeline. Fail the build if context quality drops below your threshold.

The Standard

One taxonomy for every AI tool

stAIpler defines three classes of instruction files. Native assets it compiles, imported files it normalizes, and project docs it can reference.

Class 1: Native Assets

The core stAIpler vocabulary. Compiled directly into optimized instruction bundles.
IDENTITY.md GOALS.md CONTEXT.md CONSTRAINTS.md SKILLS.md STYLE.md EXAMPLES.md TOOLS.md MEMORY.md POLICIES.md EVALS.md

Class 2: Imported Adapters

External ecosystem files normalized into native assets. Your existing files just work.
AGENTS.md CLAUDE.md GEMINI.md SKILL.md copilot-instructions.md .cursorrules .windsurfrules CONVENTIONS.md

Class 3: Supporting Docs

Project docs agents benefit from. Optionally compiled into context bundles.
README.md ARCHITECTURE.md PLAN.md API.md SECURITY.md TESTING.md CHANGELOG.md llms.txt
